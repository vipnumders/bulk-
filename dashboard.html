WhatsApp Business API

Not connected

Add your Meta WhatsApp Cloud API credentials so Bulk Messaging can send real messages. Get these from developers.facebook.com/apps → your app → WhatsApp → API Setup.

Stored in your account in Firestore, only ever read server-side by a Cloud Function — your token is never sent to or exposed in the browser.

How sending works

  • Bulk Messaging is blocked until Phone Number ID + Access Token are saved here.
  • Sending goes through a Cloud Function relay, not directly from your browser — this keeps your token private and avoids CORS issues with Meta's API.
  • Each message costs ₹0.35 from your Wallet balance, deducted server-side and refunded automatically if the send fails.
  • Meta only allows free-form text to a contact within 24 hours of them messaging you first. For true cold outbound, you need an approved message template in Meta Business Manager — plain text sends outside that window will be rejected by Meta, not by this site.
  • Test tokens from Meta's dev dashboard usually only work for a short list of verified test numbers until your app is approved for production.
